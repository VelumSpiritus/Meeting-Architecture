# The Practice for Smarties — package note

`the-practice-for-smarties-original.html` is Noah Davidson’s supplied file unchanged. `the-practice-for-smarties.html` is the offline reading copy with all seven original images restored from the session uploads. Each image was matched to the Claude artifact record by SHA-256. The reading copy uses local images and fallback fonts and omits a PDF button that depended on the original viewer; its article prose and equations are unchanged.

The essay gives the linguistic origin of the author’s gap-detection method. Circuit measurements and physical equations are documented separately in the main packet.
